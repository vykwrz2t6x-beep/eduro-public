# eduro-public

Публичная сборка фронтенда приложения «Проверка ДЗ» — статический SPA без сборки.

- Сайт: https://vykwrz2t6x-beep.github.io/eduro-public/
- Бэкенд (Cloudflare Worker): https://eduro-api.almishi.workers.dev
- Адрес бэкенда задаётся в `assets/js/config.js` (`window.API_BASE`)

Секретов в репозитории нет: ключи живут только в переменных окружения Cloudflare.
Исходники бэкенда — в приватном репозитории.
